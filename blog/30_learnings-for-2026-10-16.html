Our own rulings pushed the builder out of bounds

The design check refused problems already live on the site, and a ruling sent the builder outside the files it is allowed to change.

The design gate refused overflow already on main

What happenedLink-only diffs to the blog posts were refused round after round for 400px overflow caused by long identifiers already in the post text, and each round ended in another waive

LessonA gate that judges the whole page rather than the change keeps refusing a diff that cannot fix the fault

What changedThe design check now refuses only overflow the diff introduces

Our rulings pushed the builder outside its write paths

What happenedThree authority refusals in a row came from rulings telling the builder to delete or regenerate a results file that was already on main

LessonA ruling that has the builder touch a file it may not write causes the refusal it was meant to clear

What changedThe ruling was to leave the file untouched, and the code landed

The checks rail could not run live target tests

What happenedThree jobs were refused with the same pytest fingerprint because their tests clone public repos and run forge or slither-mutate

LessonA test that needs the network and outside tools is not a check the rail can run

What changedThe fuzz-bench profile runs pytest with -m 'not live'

The drift pass read a registry older than main

What happenedThe drift pass flagged python review as stale because the tick checkout held an older registry entry that still matched on seat

LessonA check is only as current as the checkout it reads

What changedThe tick now evaluates the registry entries main holds

Seat-tool denials hid the real stop

What happenedShell refusals kept showing up in the fizz generate run after two seat-tool fixes landed, but the score step was really stopping on a missing bench/null_check.py in fuzz-bench

LessonThe loudest refusal in a transcript is not always the one that stopped the job

What changedNone yet: the score step waits for null_check.py to land in fuzz-bench
