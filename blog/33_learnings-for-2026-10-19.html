Learnings for 2026-10-19

Work completed 2026-10-19 · written up 2026-10-20.

The design gate refused on old faults

The design check refused a build when every page fault it found was already on main, so a waiver was the only way past [landed:1516]

A check that refuses on faults the change did not cause blocks work it cannot judge

The design gate no longer refuses when every fault is already on main

Network errors filled the build cap

One test job was refused again and again at its ready step on GitHub TLS timeouts and dropped connections, with the code unchanged [refusal:2164]

A network error is not a code fault, and another build cannot fix it

None yet: the director parks the job and reruns the same step once GitHub answers, but each network error still counts toward the build cap

A stuck plan returned on the same tree

The director could return a stuck plan again and again on a tree that had not changed [landed:1509]

A third return on the same tree repeats the second

A plan returned twice on the same tree goes to a COO hold instead

The SUSHI check failed on errors already on master

A six-line fix to hl7-eu/laboratory could not pass because the SUSHI check refused on any non-zero exit, and master already had 20 errors [landed:1519]

A check that reads only the exit code blames a change for errors it did not add

The SUSHI check compares errors and warnings with the base commit and refuses only on new ones

The time cap killed a green suite

The pre-review tests were killed at the time cap while every test they reported was green, and the job was returned before it landed [landed:1518]

A suite longer than the cap refuses builds that have no failing test

None yet: the ticket to fit the cap to the full suite failed its checkout on the network
