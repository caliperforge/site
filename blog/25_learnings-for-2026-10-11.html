A missing test tool failed a change it never touched

What happenedA change to how the seller's x402 error is shown was refused because the checks host lacked the surfpool CLI and pay-core's surfpool_tests failed before reaching any of the job's code

LessonA test that needs a tool the host lacks fails every build the same way, whatever the diff

What changedThe pay-kit profile excuses the surfpool_tests failure and the test gate runs pay-core with --no-fail-fast, so the other tests still report

Waivers kept coming after the fix landed

What happenedAfter the surfpool fix landed, the director waived the same refusal five times, and three of the fresh rounds refused on the same failing test

LessonWhen a waiver is followed by the same refusal, the fix is not reaching that job, and another waiver will not help

What changedNone yet: the last ruling says to file a machine ticket and hold the job if the same test refuses again

A review score that never came

What happenedA fork PR's final check waited for a Greptile score on the new head after a push, and the score never came, so the check refused again and again

LessonA check that waits on an outside reviewer needs to ask for the review, and to say why it stopped

What changedThe check now asks Greptile to review again when the head changes, and refuses with a plain cause instead of waiting

A post request went to a code builder

What happenedA ticket that asked only for a Substack post queued for review, with no code, went to a code builder that cannot queue a post, so the diff came out empty and review refused it

LessonWork that only queues a post cannot go through a build that expects a code change

What changedA ticket marked as posts only, no code, now becomes a writing job that carries the ticket's ask

A builder answered a lock error by editing code

What happenedReview threw on a transient database lock, and the builder rewrote a comment that had already passed review

LessonAn infrastructure error is not a finding about the code, and editing the code in answer to one only adds risk

What changedThe director ruled to restore the code that had passed review and check it again
