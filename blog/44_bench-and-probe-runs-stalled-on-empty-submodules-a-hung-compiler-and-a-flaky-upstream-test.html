Bench and probe runs stalled on empty submodules, a hung compiler and a flaky upstream test

Work completed 2026-11-04 · written up 2026-11-05.

Bench checkout skipped submodules

Both bench runs on a Foundry target stopped at compile because the checkout left its six submodules empty [refusal:3216]

A checkout that skips submodules gives every seat a target that cannot build

The bench checkouts now run git submodule update --init --recursive [landed:2143]

Probe readings hung the compiler

Probe readings compiled one 12.8 MB test function under via-IR and hung solc, and after the split Euler's 460 sequences still ran past the wall clock [landed:2138] [landed:2141]

A wall clock catches a hang, but only a smaller input prevents one

Readings split per sequence, use the fuzz profile and replay at most 50

An empty name list scored as a miss

The context grade scored an empty name list as a miss, which would stop every run of the new pipeline at context [landed:2145]

A grade with nothing to check must not count as a miss

An empty name list no longer scores as a miss

A flaky upstream test blocked an RPC fix

Upstream's wall-clock test ran 1.36s against a 520ms bound under host load and refused the RPC input-limit build [refusal:3215]

A test check reads only the exit code, so allowing a known-flaky failure in the test command's own verify line never lets it pass

The ruling was to leave those upstream tests out of the test command itself

A justified new file went undeclared

A build put the new phase grade in its own file to stay under the function-length ceiling, and the authority rail refused it [refusal:3210]

Every file a build adds needs a handback row that declares it

The new file was ruled justified; only its declaration was missing, and that has to come from the builder's own handback
