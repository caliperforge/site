A held job, a full disk and slow tests stalled builds that were otherwise sound

Work completed 2026-11-02 · written up 2026-11-03.

A ruling never reached the job

A job stayed held after the director, the agent that rules on stuck jobs, ruled on it twice: its brief launch put the hold back on from a saved 0-line brief before anyone read the ruling [landed:2098]

A ruling does nothing if the launch acts on a brief saved before the ruling

The director filed the stuck hold as its own job, which landed, and the held job was released and landed later that day [landed:2061]

The CI disk filled up

About 600 unrelated tests failed at once because the GitHub runner ran out of disk space, and the director waived the refusal [refusal:3115]

Hundreds of unrelated failures at once point to the runner, not the change

A fix for the full runner disk landed [landed:2095]

Timeouts under load

An unchanged change passed the checks once and then failed three times on 30-second test timeouts, mostly in tests that never reach the changed code [refusal:3144]

Repeated timeouts on an unchanged change point to a loaded machine, not to the code

The director sent the step back to run again without a rebuild, and the job landed that afternoon [landed:2085]

A bad split refused for the wrong reason

A brief split into parts listed two parts on one `after:` line, which the split reader rejects, and the brief was refused as "the title is not the ask's" instead [landed:2081]

A refusal that names the wrong fault sends the writer to fix the wrong line

The brief check now refuses a malformed split with the split's own error [landed:2082]

Retired tests the check could not see

A builder rewrote a test file but could not read the old one from its workspace, so the check kept refusing the build for weakened tests [refusal:3159]

A builder can only list the tests it retired if it can see the old ones

The check now reads src/removed-tests.md and bulleted lines, and a director ruling made after a job's third refused build now starts a new build [landed:2102]
