Rulings the checks couldn't read, and a sandbox that stopped the fuzzer

Work completed 2026-11-11 · written up 2026-11-12.

A ready check that ignored rulings

A docs-only change kept going back through rebuild and review to the same red CI run, because the final ready check ignored three director rulings that the red came from an unrelated hardware flake [refusal:3449]

A ruling the check cannot read changes nothing

The final ready check now accepts a director's ruling that a red CI run doesn't count when the code hasn't changed

Research notes the job could not write

A research job's note-writing step was blocked from the job's own output folder, so its notes kept two cells known to be wrong and the job could not finish [landed:2352]

A job that cannot write its own output can never meet its finish line

That step may now write to the job's output folder, with no network access

A sandbox that blocks local ports

Every generator run on the euler-earn-m01 bench died because the sandbox would not let the fuzzer's log viewer listen on a local port, so no sub-agent ran and the bench refused each round [refusal:3465]

A sandbox that blocks local ports stops the fuzzer before it starts, whatever the generator changes

None yet: a person has to open a ticket to let that seat bind local ports

A moved test read as a skipped one

A Rust change's checks refused it repeatedly for weakening a test, when the test was an unchanged skipped hardware diagnostic that git's diff showed as moved [refusal:3474]

A skipped test that only moved is not a new skip

The weakened-test check now ignores a skipped test that is unchanged but shown as moved

A runner outage taken for a code fault

A change's CI failed three times because GitHub's runner could not look up Ubuntu's package servers while installing browser fonts [refusal:3460]

An outage on the runner says nothing about the diff, and waiting a fixed hour doesn't show it has passed

The director sent the change back as soon as another job's CI passed, without waiting out the hold
