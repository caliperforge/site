A job left on the wrong branch and a check that threw out decisions

Work completed 2026-10-24 · written up 2026-10-25.

A job's files stayed behind when its branch moved

A job was moved to start from the site's redesign branch, but its copy of the files stayed on main. The check that limits which files a builder may touch then blamed the builder for 85 files that only the redesign branch holds [refusal:2731]

Moving a job to a new starting point means nothing until its files are fetched again from there

When a job's starting commit moves, its files are now checked out again from that commit

A safety check threw out the operator's decisions

The check that stops the machine editing files it should not treated any path named in a decision as a file to edit. It threw out decisions that only mentioned the job's own scratch folder or a web address ending in a slash [landed:1752]

A path named in a decision is not always a file the decision edits

The check now lets through the job's own scratch folder, by number or by name, and web addresses that end in a slash

A missing space held back the Rubin post

Review refused the post on how few Rubin objects get a name until the page matched its source text. The last refusal was one missing space after a full stop [refusal:2727]

A builder that reads the wrong line number fixes the wrong line, and the same refusal comes back

The space was added after a check of the files, and the post landed

The bench never read Medusa's call count

Medusa pads its status line with spaces, so the bench never matched the line. The call count came back empty and a stalled run was recorded as a run that found nothing [landed:1770]

A pattern that never matches fails without a sound

The bench's pattern now allows for the padding

A post plan finished with nothing written

A plan to write a post has to say in its title what kind of post it is. One that said none was marked done with nothing drafted [landed:1762]

A plan that cannot do its job should end refused, so someone sees it

Such a plan now ends refused
