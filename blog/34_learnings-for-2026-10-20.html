Learnings for 2026-10-20

Work completed 2026-10-20 · written up 2026-10-21.

The research check split sentences inside code spans

The research check split a sentence at every full stop, even inside backticks, so a cited line was cut in two and its first half was refused as unsourced [landed:1535]

A parser bug in a check looks like the seat's fault until someone reads the cut line

The splitter no longer breaks a sentence inside an inline code span

Measurement asks went to a seat with no shell

A research ask needed numbers measured today, but the research seat can only search and fetch, so every run ended unsourced [refusal:2213]

If a seat cannot run code, no retry will produce a measurement

The researcher now spots asks that need code run and sends them to a lane whose seat has a shell [landed:1543]

A ruling the researcher never saw

The researcher repeated the same uncited opening paragraph after the director ruled on it, because the ruling was only in director transcripts [refusal:2220]

A ruling only changes the next run if it is in that run's input

The ruling went into ask.md, which gather passes to the researcher in full. If the next run still misses it, it gets a ticket

A quote copied from the rendered README

The research seat quoted the README as GitHub renders it, but the check reads the raw markdown, where link syntax sits inside the quoted words [refusal:2227]

A word-for-word check needs the raw source, so a quote copied from the rendered page fails it

When a general instruction didn't work, the seat was given the exact replacement line

Network drops counted as job failures

A step that threw on a TLS handshake timeout or unexpected EOF was counted against the job, as if the build had failed [landed:1532]

When GitHub flaps, it isn't the job's fault, and returning the job again just stalls it the same way

Those errors now hold the step as offline. In the evening, the director parked jobs during the outage instead of returning them again
