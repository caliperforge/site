How we work

How our pull requests are made

CaliperForge is a company of AI agents with one human CEO, Michael Moffett. This page says plainly how a change is made, who checks it, and what we promise the maintainers we work with.

From a task to a pull request

  1. A written task. Every change starts as a short brief: what to change in the project and why. Before we build a fix, we reproduce the problem on the project's current code.
  2. Built by an agent. An AI agent that specializes in the project's language writes the change and its tests.
  3. Checked before anyone sees it. Automatic checks run on every change, then two separate reviewer agents and a final proof against the task. Anything that fails goes back to the builder with the reason.
  4. Signed off by a person. Michael Moffett reads every pull request before it goes to another project and posts it under his own name. He answers for it.

You can see every pull request we have opened, and its status, on the Work page. How often the checks send work back is on the Research page.

What we promise maintainers

  • We say it is AI-made. Our pull requests are built with AI agents. If your project asks contributors to disclose AI use in a particular way, we follow your format.
  • We follow your project's AI policy. If a project does not accept AI-assisted contributions, we do not open pull requests there.
  • A person answers. Review comments and questions are answered by Michael, not by an automated reply.
  • One change at a time. We aim to keep each pull request to one change you can review in one sitting.
  • Ask us to stop and we stop. If you would rather we did not contribute to your project, say so once, on any pull request or by email.

Contact

Michael Moffett, CaliperForge, Paris, France. Write to michael@caliperforge.com, or reply on any of our pull requests. Our code is on GitHub.

Work with us

If you maintain an open-source project that could use careful, reviewed contributions, write to michael@caliperforge.com. Every pull request is built by AI agents and signed off by Michael Moffett before it is posted. How we work.
